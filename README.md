# CR881x QoS feed

Independent LuCI app for per-socket speed limits on CR881x + YT921x.
The compact interface follows the active theme, including Zcop palettes, and
works with the standard Bootstrap theme as a fallback.

```text
src-git zcopapp https://github.com/zcop/luci-app-cr881x-yt921x-qos.git
```

See [usage and validation](luci-app-cr881x-yt921x-qos/README.package.md).
